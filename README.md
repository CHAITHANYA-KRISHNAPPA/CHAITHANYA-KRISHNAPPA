## 🔥 Featured Projects

### 🌦️ ANVIKSHA-8Bit CPU

ANVIKSHA is an educational 8-bit CPU designed and implemented to demonstrate the fundamental concepts of processor architecture, digital logic, and computer organization. It was initially developed and verified using Logisim Evolution, and later implemented on the Basys 3 FPGA using Verilog HDL and Xilinx Vivado. The processor successfully executes instructions and sample programs such as multiplication and Fibonacci sequence generation, validating its functionality in both simulation and hardware environments.

### 🏠 Energy-Efficient Smart Home System

Developed a Wi-Fi-enabled Smart Home Automation System using the ESP32 microcontroller to provide real-time monitoring and remote control of household appliances through a custom web-based dashboard. The system integrates IoT technology to enable users to control devices over a wireless network while continuously monitoring energy consumption using current and voltage sensors. A responsive web interface was designed to visualize power usage, display electrical parameters, and facilitate efficient appliance management. By providing real-time insights into energy consumption and enabling remote operation, the system promotes energy efficiency, reduces unnecessary power usage, and enhances user convenience through an intelligent and cost-effective home automation solution.

### ⚡ ELECTROYODHA – Educational Learning Platform

Led the development of a student-focused educational website aimed at simplifying electronics concepts for beginners and engineering students. The platform provides structured learning resources covering fundamental electronic components, circuit basics, digital electronics, microcontrollers, and Arduino programming with practical examples and demonstrations. Developed using HTML, CSS, and JavaScript, the website features a responsive and user-friendly interface that enables easy navigation across various learning modules. The project emphasizes interactive learning by presenting complex technical concepts in a clear and accessible manner, making it an effective educational resource for self-paced learning and academic support in electronics and embedded systems.
### 💎 Luxury Jewelry Website

Designed and developed a premium jewelry showcase web application to provide an elegant and engaging platform for displaying luxury jewelry collections. The application features a modern, responsive, and user-friendly interface that enables users to browse products, explore detailed item information, and navigate seamlessly across different categories. Developed using HTML, CSS, SQL, and foundational React concepts, the project incorporates efficient database management for storing and retrieving product information while maintaining a visually appealing design. The implementation emphasizes responsive web design, intuitive navigation, and enhanced user experience, demonstrating proficiency in front-end development, database integration, and modern web development practices.
